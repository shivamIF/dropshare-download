# DropShare

Send files between Mac, Windows and Android over Wi-Fi, like AirDrop.

## Download

**[Get the latest version](https://github.com/shivamIF/dropshare-download/releases/latest)**

| Device | File |
|---|---|
| Windows | `DropShare-windows.zip` |
| Android | `DropShare-android.apk` |
| Mac | `DropShare-mac.zip` |

## Install

**Windows**
1. Unzip `DropShare-windows.zip` (right-click → Extract All).
2. Open the folder and run `drop_share.exe`. Keep the other files next to it.
3. If you see "Windows protected your PC", click **More info → Run anyway**.
4. When the firewall asks, allow **Private networks**.

**Android**
1. Open `DropShare-android.apk` on the phone.
2. If asked, allow your browser or file app to **install unknown apps**.

**Mac**
1. Unzip `DropShare-mac.zip` and drag **DropShare** into **Applications**.
2. The first time, right-click DropShare → **Open → Open**. If macOS still blocks it, go to
   **System Settings → Privacy & Security** and click **Open Anyway**.

## Use

- Put both devices on the **same Wi-Fi** and open DropShare on both.
- Tap the other device and pick files. The other device taps **Accept**.
- Or share straight from your files: **Share → DropShare** (Android, Mac Finder),
  or right-click → **Send to → DropShare** (Windows).

These apps are not signed by Apple, Microsoft or Google, which is why the warnings above appear.
